# Session 1: Introduction to Computers: Hardware & Software

## Hardware vs Software
* **Hardware:** The physical parts of a computer that you can touch (e.g., monitor, keyboard, motherboard, CPU).
* **Software:** The programs and instructions that tell the hardware what to do (e.g., Windows 11, MS Office, Google Chrome).

## Inside the Machine
* **CPU (Central Processing Unit):** The brain of the computer.
* **RAM (Random Access Memory):** Short-term memory for active tasks.
* **Storage (HDD/SSD):** Long-term memory for saving files.

## Activity: Identify Components
1. In the lab, physically identify the monitor, keyboard, mouse, and system unit (or laptop chassis).
2. Point out the USB ports, power button, and audio jacks.

## Activity: Safe Power Procedures
* Practice turning the computer on.
* Practice shutting the computer down safely using the Start Menu. **Do NOT just hold the physical power button!**
