# 🧠 Key Concept

- Choosing the Right Chart Type

- A chart turns a table of numbers into a picture, making patterns and comparisons easier to see at a glance than reading raw numbers.

- The three most common chart types:

- Simple rule: if it compares totals, use Column; if it shows a share of 100%, use Pie; if it tracks change over time, use Line.

# 🧠 Key Concept

- Parts of a Chart & How to Build One

- Every good chart has these parts:


### 🔹 Building A Chart — The Basic Steps
1. Select the data, including its header row. 2. Go to the Insert tab and choose a chart type. 3. Add a clear title and axis labels. 4. Format colours and legend position so the chart is easy to read.

# 💻 Hands-on Practice

- **Part 1** — Do This in Lab

1. Create table: Month (Jan–Aug) in A1:A9, Passengers (000s) in B1:B9
2. Enter 8 monthly passenger numbers (e.g. 120, 135, 128, 150, 142, 160, 155, 170)

7. Move chart below the data table
