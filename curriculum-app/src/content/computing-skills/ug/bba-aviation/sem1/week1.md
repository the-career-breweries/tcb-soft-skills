# Hardware vs Software

What is the difference?

* **Hardware:** The physical parts of a computer that you can see and touch (e.g., monitor, keyboard, motherboard, CPU).
* **Software:** The programs and instructions that tell the hardware what to do (e.g., Windows 11, MS Office, Google Chrome, Aviation Management Systems).

---

# Inside the Machine

The core components that make a computer work:

* **CPU (Central Processing Unit):** The brain of the computer that processes instructions.
* **RAM (Random Access Memory):** Short-term memory for active tasks. It clears when the power is turned off.
* **Storage (HDD/SSD):** Long-term memory for saving your files and programs permanently.

# Safe Power Procedures

It is critical to power cycle your machine correctly to prevent data corruption.

* **Turning On:** Press the power button once and wait for the Operating System to load.
* **Turning Off:** Always use the Start Menu -> Power -> Shut Down. 
* ⚠️ **Do NOT just hold the physical power button or pull the plug!** This can corrupt your files.
